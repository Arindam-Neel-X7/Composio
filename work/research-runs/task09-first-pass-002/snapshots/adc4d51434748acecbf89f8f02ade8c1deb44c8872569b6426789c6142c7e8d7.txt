Cliq-MCP: AI WorkBuddy for Zoho Cliq
AI WorkBuddy is an intelligent assistant for Zoho Cliq that provides smart automation and productivity features through the Model Context Protocol (MCP). It combines the power of modern AI with seamless Cliq integration to enhance team collaboration and productivity.
🎯 Key Features
🤖 AI-Powered Capabilities
Smart Summarization: Automatically summarize channel conversations with key insights
Task Extraction: Identify and extract action items from discussions
Meeting Minutes: Generate structured meeting minutes from conversations
Issue Classification: Intelligent categorization and prioritization of support tickets
Context-Aware Responses: AI understanding of workplace communication patterns
🔧 Technical Excellence
MCP Protocol: Built on the Model Context Protocol for seamless AI integration
Multi-Provider Support: Compatible with OpenAI GPT and Anthropic Claude
Professional Architecture: Clean, scalable, and maintainable codebase
Comprehensive Testing: 48% test coverage with unit and integration tests
Docker Ready: Full containerization support for easy deployment
⚡ Cliq Integration
Webhook Support: Real-time event processing from Zoho Cliq
Rich Card Responses: Beautiful, interactive responses in channels
Command Interface: Intuitive slash commands for AI features
Error Handling: Graceful error handling with user-friendly messages
🚀 Quick Start
Prerequisites
Python 3.11+
Zoho Cliq account with bot permissions
OpenAI API key or Anthropic API key
Installation
Clone the repository
git clone https://github.com/rohansen856/cliq-mcp
cd cliq-mcp
Set up environment
# Copy environment template
cp .env.example .env
# Edit .env with your configuration
nano .env
Install dependencies
python -m venv venv
source venv/bin/activate # On Windows: venv\Scripts\activate
pip install -r requirements.txt
Start the application
# Using the start script (recommended)
./scripts/start.sh
# Or manually
python -m src.main run
Docker Deployment
# Build and run with Docker Compose
docker-compose up -d
# Check status
docker-compose ps
# View logs
docker-compose logs -f cliq-mcp

🔧 Configuration
Environment Variables
# Required Settings
WEBHOOK_SECRET=your-webhook-secret-key
SECRET_KEY=your-super-secret-key
# AI Provider (choose one)
OPENAI_API_KEY=sk-your-openai-api-key
ANTHROPIC_API_KEY=sk-ant-your-anthropic-key
# Zoho Cliq Integration
CLIQ_BOT_TOKEN=your-cliq-bot-token
CLIQ_CLIENT_ID=your-cliq-client-id
CLIQ_CLIENT_SECRET=your-cliq-client-secret
# Server Configuration
MCP_SERVER_HOST=localhost
MCP_SERVER_PORT=8001
WEBHOOK_HOST=0.0.0.0
WEBHOOK_PORT=8000
# Application Limits
MAX_MESSAGE_HISTORY=50
SUMMARY_MAX_LENGTH=500
TASK_EXTRACTION_LIMIT=10

Troubleshooting
Common Issues:
API Key Errors
Error: No AI provider API key configured
Solution: Set OPENAI_API_KEY or ANTHROPIC_API_KEY in .env
Webhook Authentication
Error: Invalid signature
Solution: Verify WEBHOOK_SECRET matches Cliq configuration
Port Conflicts
Error: Address already in use
Solution: Change ports in .env or stop conflicting services
