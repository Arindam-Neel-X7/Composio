Supported Tools
Use these supported tools with ClickUp's MCP Server.
The ClickUp MCP exposes many of the capabilities available in our API. The real magic happens when your AI assistant combines several tools to complete a larger request.
Note: Your AI assistant will only be able to perform actions in ClickUp that you have permission to do.
Search
ToolDefinitionExample usage (for an AI assistant)
Search WorkspaceSearches for items across the entire ClickUp Workspace, including tasks, Docs, dashboards, attachments, whiteboards, Chats, and forms."Find all tasks related to the 'Q4 Marketing Launch'."
Search tasks by tagRetrieves tasks filtered by tags."Show me the tasks with the 'UX-quality' tag."
Task management
ToolDefinitionExample usage (for an AI assistant)
Create TaskCreates a new task in a specific List. You can specify details like the task name, description, assignees, due date, and priority."Create a task to 'Draft blog post' in the 'Content Pipeline' List, assign it to me, and set the due date for this Friday."
Get TaskRetrieves the full details of a single task using its unique task ID."What are the details for task 'Design-123'?"
Update TaskModifies the properties of an existing task. This can include changing the task's name, description, status, assignees, or due date."Change the status of task 'Draft blog post' to 'In Progress' and add 'Review' as a subtask."
Set Custom FieldsSet Custom Fields on tasks.
Note: Your AI assistant understands the Custom Fields, options, and supported values that are available on tasks."Set the 'release number' to '4.07'."
Get Custom FieldsRetrieves the Custom Fields available on a List, Folder, Space, or Workspace."What Custom Fields does the 'Bugs' List have?"
Delete taskDeletes a task or subtask.
Note: Your AI assistant may confirm the correct task is selected before deleting the task."Delete the "testing use only" task."
Merge tasksMerges one or more tasks into a target task, combining their comments, attachments, subtasks, and tracked time."Merge the duplicate 'Login bug' tasks into the original one."
Manage tasks in bulk
Bulk actions run through the Execute Operator tool (see Generic operations).
ToolDefinitionExample usage (for an AI assistant)
Create tasks in bulk (clickup_execute_operator, task.create_many)Creates multiple tasks in a specified List with a single call."Add these items as new tasks in the 'Onboarding' List: 'Send welcome email', 'Schedule orientation', and 'Set up hardware'."
Update tasks in bulk (clickup_execute_operator, task.update_many)Applies the same change to multiple tasks at once. This is useful for changing the status, assignee, or due date for a group of tasks simultaneously."Move all tasks in the 'Sprint 3' List with the 'Ready for Review' status to 'In Review'."
Task attachments
ToolDefinitionExample usage (for an AI assistant)
Attach File to TaskUploads and attaches a file (like a document, image, or ZIP file) to a specific task."Attach this document [file_upload] to the 'Submit Final Report' task."
Request Attachment UploadGets a short-lived upload link for adding a large file (up to 1 GB) to a task or Chat."Upload this recording to the 'Customer Interview' task."
Download Task AttachmentRetrieves a file attached to a task."Open the spec PDF attached to task 'Design-123'."
Task comments
ToolDefinitionExample usage (for an AI assistant)
Get Task CommentsRetrieves all comments from a specific task."What's the latest update on the 'Develop new feature' task?"
Get Threaded RepliesRetrieves threaded replies under a parent task comment."Summarize this comment thread and tell me my action items."
Create Task CommentAdds a new comment to a task. This can be used to ask questions, provide updates, or @mention other team members."Add a comment to task 'Design-123' saying: '@Mark, can you please provide the latest mockups?'"
Create CommentAdds a comment to a task, List, or view, or replies to an existing comment."Reply to Mark's comment and say the mockups are attached."
Update CommentEdits, resolves, or reassigns an existing comment."Resolve my comment on the 'Design-123' task."
Delete CommentDeletes a comment."Delete my last comment on the 'Design-123' task."
Task tags
ToolDefinitionExample usage (for an AI assistant)
Create Space TagCreates a new tag that every task in a Space can use."Create an 'Urgent' tag in the 'Engineering' Space."
Add Tag to TaskApplies an existing tag (label) to a task for categorization."Add the 'Urgent' tag to task 'Fix login bug'."
Remove Tag from TaskRemoves a specific tag from a task."Remove the 'Backend' tag from task 'Update button color'."
Task relationships
ToolDefinitionExample usage (for an AI assistant)
Add task linkRelate two tasks by linking them."Link feature 123 with design for feature 123."
Remove task linkRemove links between tasks."Remove the link between feature 123 and scope designs for feature 123."
Add dependencyCreate a dependency relationship between tasks."This task is blocked by its subtask called 'support Google authentication'."
Remove dependencyRemove a dependency relationship between tasks."Remove the dependency between feature 123 and support Google authentication."
Move and add tasks to other Lists
ToolDefinitionExample usage (for an AI assistant)
Move task to a new ListMove a task to a new home List."Move the feature 123 task from the Backlog List to 'Sprint 3'."
Add task to another ListAdd a task to another List."Add the feature 123 task to 'Sprint 3'."
Remove task from a ListRemove a task from an additional List. The task stays in its home List."Take the feature 123 task out of 'Sprint 3'."
Time tracking
ToolDefinitionExample usage (for an AI assistant)
Get Task Time EntriesRetrieves all time log entries for a specific task."How much time has been logged for the 'Client Research' task?"
Get time entries for multiple tasksRetrieves time entries and totals across tasks, filtered by date range, assignee, or billable status."How much time did I log last week?"
Start Time TrackingStarts a timer for a specific task for the current user."Start tracking time for the 'Code Review' task."
Stop Time TrackingStops the currently active timer for the user."Stop the timer."
Add Time EntryManually adds a block of time (a time entry) to a task, including a start and end time or a duration."Log 2 hours of work on the 'Database optimization' task for yesterday."
Get Current Time EntryChecks if the user has a timer currently running and, if so, returns the details of that time entry."What am I currently tracking time for?"
Workspace Hierarchy
ToolDefinitionExample usage (for an AI assistant)
Get Workspace HierarchyRetrieves the full structure of the Workspace, including all Spaces, Folders, and Lists."Show me all the Lists in the 'Engineering' Space."
Create ListCreates a new List within a specific Space. To create a List inside a Folder, use Create List in Folder."Create a new List named 'Sprint 4 Planning' in the 'Product' Space."
Create List in FolderCreates a new List specifically inside a designated Folder."Inside the 'Marketing Campaigns' Folder, create a new List called 'Social Media Content'."
Get ListRetrieves the details and settings for a single List."What are the custom statuses for the 'Bugs' List?"
Update ListModifies the settings of an existing List, such as changing its name, description, or status."Rename the 'New Ideas' List to 'Approved Ideas'."
Get FolderRetrieves the details for a single Folder, such as its ID, name, and the Space it belongs to."Which Space is the 'Client Projects' Folder in?"
Create FolderCreates a new Folder within a specific Space."Create a new Folder named 'Q1 Projects' in the 'Operations' Space."
Update FolderModifies the settings of an existing Folder, such as changing its name."Rename the 'Design' Folder to 'Design Team'."
Members and assignees
ToolDefinitionExample usage (for an AI assistant)

Find Member by NameSearches for a Workspace member using their name or email."What is David Smith's user ID?"
Resolve AssigneesA utility to confirm and retrieve the user objects for a list of potential assignees, often used before adding them to a task."When you say, 'Assign this task to Mark and Sarah,' this tool finds the correct user IDs for 'Mark' and 'Sarah'."

Docs
ToolDefinitionExample usage (for an AI assistant)

Tool details
To connect a client and sign in, see MCP Server Setup Instructions. Tool names below are the exact names your MCP client sees.
Every tool acts as the signed-in user, with that user's ClickUp permissions, exactly as in the app. The server adds no access of its own. In ChatGPT Team, Enterprise and Edu workspaces, only owners and admins can configure MCP servers. Every tool also accepts an optional workspace_id (required when the user belongs to more than one workspace; if it's missing, the server lists the choices).
Columns: Type is Read or Write. Sensitive marks tools that delete or irreversibly overwrite data, post content as the user, or move files. Side effects covers what changes in ClickUp and who is notified.

Generic operations (Unified API)
ToolTypeSensitiveInputsReturnsSide effects / permissions
clickup_get_operatorsReadNoOptional filterAllowed operations and their inputsNone
clickup_get_schemaReadNoOptional filterHow ClickUp objects relateNone
clickup_execute_operatorWriteYesmodel, operator. Optional: parameters, body, queryThe operation's resultRuns one allowed operation as the user. Don't retry a timeout; the operation may have completed.
Allowed operations: Tasks: read many by ID, create many (task.create_many), update many (task.update_many, one shared change applied to every named task), archive, unarchive. Lists and statuses: update a List; read statuses of a List, Space or Folder; add, rename or remove a Space's statuses. Custom fields: create, list. Views: create, update, read, list. Forms: create, update, read, list. None of these delete anything; archive is reversible. Bulk update and archive must name task IDs.
Status handling
Success: a normal result. Writes return success: true plus the IDs of what changed.
Failure: a result with isError: true and a JSON body {"error": "..."} (see Errors).
No pending states: every tool completes in a single request; there is nothing to poll.
Paging: pass next_cursor back as cursor. Cursor-paged read tools also return has_more.
Partial results: some writes return warnings naming parts of the request that weren't applied (e.g. an unresolvable watcher) while the rest succeeded.
Task statuses: statuses are defined per List. Use clickup_get_list or clickup_get_task (with expand_statuses) to find a List's valid statuses before setting one.

ErrorMeaningRetry?
HTTP 401 with WWW-Authenticate: Bearer ... error="invalid_token"Sign-in missing or invalidSign in again
HTTP 400x-workspace-id header isn't a numberFix the header
HTTP 429 with Retry-After: 60Too many requests to the serverWait, then retry
JSON-RPC -32602 Unknown tool: <name>Tool doesn't exist or is switched offNo
Tool result isError: true, {"error":"Failed to <action>: <reason>"}The operation failedSee below
Tool result errorCode: RATE_LIMIT_EXCEEDED, retryAfter: <seconds>Daily or per-plan limit reachedRetry after retryAfter seconds
Bad input, permission or "not found" errors: don't retry; change the request.
"Request timed out" or "ClickUp server error" on a read: safe to retry.
Same errors on a write: check whether it happened first. Creates, sends, comments and time entries make a second copy if repeated.
Rate limits
Server: 1,000 requests per minute per connection.
File uploads: 20 per 15 minutes per user, up to 1 GB per file.
Daily MCP call limits by plan: see ClickUp's MCP Server.
