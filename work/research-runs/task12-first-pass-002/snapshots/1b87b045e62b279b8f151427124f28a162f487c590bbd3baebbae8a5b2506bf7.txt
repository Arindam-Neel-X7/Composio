# Claude Code
Follow these steps to add Ahrefs MCP server to Claude Code:
- Run from terminal `claude mcp add ahrefs https://api.ahrefs.com/mcp/mcp -t http`
- Launch Claude and run `/mcp`
- Authenticate the MCP Server
![](../images/clc-1.jpg)
- Login to Ahrefs account, select workspace and click "Allow"
![](../images/clw-4-3.jpg)
- A success message will be displayed. Recheck MCP server and now is connected and authenticated.
![](../images/clc-2-2.jpg)
- Verify that the query returns results.
![](../images/clc-3-3.jpg)
