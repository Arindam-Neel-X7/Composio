Scrape HTML
Retrieve the raw HTML of any webpage with the Scrape HTML endpoint, supporting browser rendering, geo-targeting, and waiting for DOM selectors.
This endpoint scrapes a target URL with Scrape HTML that supports browser rendering, geo-targeting via proxy, and waiting for specific DOM selectors before extracting content.
Note
Use the Scraper API Server (https://api.mrscraper.com) host when calling this endpoint.
This is the same endpoint as the Scrape HTML use case in the Scraper API Playground.
html must be set to true.
When screenshot is set, browserRendering is forced to true.

Query Parameters
url*string
The full URL of the page you want to scrape. Must include the protocol (https://). You can also paste a cURL command here to auto-apply all settings.
Formaturi
html*boolean
Returns the raw HTML of the page. Must be set to true for this use case.
Defaulttrue
browserRendering?boolean
Controls whether the page is loaded in a browser. Leave it out (None in the Scraper API) to load the page without a browser first and switch to a browser automatically if the request is blocked. Set true to always load the page in a browser, which JavaScript-heavy sites, SPAs, and pages that load content dynamically need. Set false to never use a browser.
timeout?integer
Maximum seconds to wait for the scrape before the request times out. Up to 330, after which the API stops waiting. Increase for slow or complex pages.
Default300
Range1 <= value <= 330
warmStart?boolean
Opens the site's home page first to warm the session before loading the target URL. Useful for sites that expect a normal browsing session before deeper pages.
Defaultfalse
blockResources?boolean
Blocks images, fonts, and stylesheets from loading. Speeds up scraping and reduces bandwidth usage.
Defaultfalse
waitForSelector?string
Waits until a specific CSS selector or text appears on the page before returning it, such as #results. Up to 500 characters. Useful for content that loads asynchronously after the initial page load.
Lengthlength <= 500
action?string
Routes the request to a specific scraper action, or simply flags it. Useful for separating analytics per domain.
geoCode?string
Two-letter country code to load the page from, such as us or gb. Defaults to the United States.
Default"us"
Length2 <= length <= 2
saveResult?boolean
Saves the result to the Result tab.
Defaulttrue
maxAge?integer
Serves a cached result of the same request when it is newer than this age, in milliseconds, such as 86400000 for 1 day. Up to 604800000 (7 days). Omit or send 0 to always scrape fresh. A cached result costs the same tokens as the original scrape.
Range0 <= value <= 604800000
tokenCap?integer
Maximum total tokens the scrape and its retries can use. Automatic retries are bounded by this cap, so the total tokens for a single run stay at or below the value you set. Omit for no limit.
Range1 <= value
maxRetries?integer
Maximum number of retries for the request. Omit for no limit.
Range0 <= value
screenshot?string
Also captures a screenshot of the rendered page as a base64-encoded PNG. full captures the entire scroll height, top captures the first viewport, and <width>x<height> sets the viewport size in pixels with an optional -<zoom> percent, such as 1280x800 or 1920x1080-75. Width and height range from 100 to 3840, zoom from 25 to 300. The image is a base64-encoded PNG. When screenshot is set, browserRendering is forced to true.
Match^(full|top|[0-9]{3,4}x[0-9]{3,4}(-[0-9]{2,3})?)$
