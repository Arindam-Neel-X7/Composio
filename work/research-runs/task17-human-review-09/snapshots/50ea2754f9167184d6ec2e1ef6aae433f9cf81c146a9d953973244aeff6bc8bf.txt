Introduction
👋 Welcome
Aircall's developer platform is the foundation for every integration, embedded experience, and AI-native app built on top of our AI-powered customer communications platform.
Whether you're building for your own team or publishing to thousands of businesses, this page gives you a clear starting point: what you can build, where to begin, and which resources to use next.
What can you build?
Aircall's developer platform gives you three ways to build voice and messaging experiences with APIs, webhooks, and AI-native tools.
Classic integrations
Connect Aircall to any business tool using our REST API and webhooks.
AI integrations
Build MCP-compliant integrations for Aircall's AI Virtual Agent.
🚧 Coming soon
Embedded experiences
Use the Everywhere SDK to embed the Aircall workspace directly inside your own product.

Developer resources
Here's a quick map of everything available in this portal.
Documentation
These docs are built to help you learn the Aircall product, understand what you can build, and find inspiration for your integrations.
REST API
The foundation for every Aircall integration. Manage calls, messages, AI agents, users, numbers, and more — fully documented with detailed schemas, and request and response examples in the API reference.
Webhooks
Real-time event notifications for everything that happens on a call. Full event types and payloads are documented in the API reference: Webhooks section.
Build for Aircall AI
Guides and templates for building MCP-compliant integrations for the AI Virtual Agent. 🚧 Coming soon.
Everywhere SDK
Embed the Aircall workspace inside any web product with a few lines of JavaScript. Full setup and API docs in the SDK reference.
Developer tools
Postman collection, example projects, and client libraries to speed up your build.
