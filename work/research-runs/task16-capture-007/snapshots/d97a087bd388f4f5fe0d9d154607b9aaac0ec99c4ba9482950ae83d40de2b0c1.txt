# Get started with Consensus MCP
> Search 400M+ scholarly articles, including 350M peer-reviewed papers and all of PubMed, from Claude, ChatGPT, Cursor, Microsoft 365 Copilot and other MCP clients.
One hosted server covers every field of science, so you don't need separate PubMed, OpenAlex or Semantic Scholar servers. Your assistant gets ranked papers it can filter by study design, sample size and journal quality, and cites real studies in its answers. Connect your client below. You'll be searching in under 2 minutes.
> [card] [What you can build with the Consensus MCP](https://docs.consensus.app/use-cases.md)
>
> MCP is the fastest way to give an assistant or agent paper search. Owkin plugged Consensus MCP into its agentic AI scientist and went from curated PubMed abstracts to 25x the paper coverage in days. Browse the use cases.

## How Consensus compares
In blinded evaluations on real user queries, Consensus search returns more relevant papers than Google Scholar and than frontier models with web search. See [Benchmarks](https://docs.consensus.app/benchmarks.md).
> [card] [More relevant than Google Scholar](https://docs.consensus.app/benchmarks.md#consensus-vs-google-scholar)
>
> 88.1% vs 81.8% precision on 500 real user queries, judged blind by PhD researchers.
> [card] [Beats GPT-5.5 and Opus 4.8, 10x faster](https://docs.consensus.app/benchmarks.md#consensus-vs-frontier-models)
>
> More relevant top-20 papers at a median of 8.7 seconds, versus 75 to 103 seconds.

> [accordion] API key (Bearer token)
>
> Use an API key for clients without OAuth, headless agents, and server-side automations. Send it in the `Authorization` header on every request to `https://mcp.consensus.app/mcp`:
>
> ```http theme={null}
> Authorization: Bearer YOUR_API_KEY
> ```
>
> Create a key from your profile icon under **API & MCP Dashboard** → **Keys and clients** → **New key**. The key gets its owner's plan limits and draws from the same monthly pool as the API. See [MCP plans and access](https://docs.consensus.app/mcp-plans-and-access.md).
>
> **JSON config** (Cursor, VS Code, and most clients that accept headers):
>
> ```json theme={null}
> {
> "mcpServers": {
> "consensus": {
> "url": "https://mcp.consensus.app/mcp",
> "headers": {
> "Authorization": "Bearer YOUR_API_KEY"
> }
> }
> }
> }
> ```
>
> **Claude Code:**
>
> ```bash theme={null}

## Using Consensus with ChatGPT Deep Research
Consensus also works with ChatGPT Deep Research. When Deep Research uses the Consensus app, it can search Consensus for relevant papers and retrieve full paper details for cited results.
**1. Connect the Consensus app**
Connect the Consensus app in ChatGPT using the steps above.
**2. Start a Deep Research request**
Start a Deep Research request in ChatGPT.
**3. Ask ChatGPT to use Consensus**
Ask ChatGPT to use Consensus for peer-reviewed research, for example:
> Use Consensus to research the evidence on exercise for depression. Prioritize systematic reviews, meta-analyses, and randomized controlled trials.
Deep Research may run multiple Consensus searches, refine filters, retrieve paper details, and return a cited synthesis with direct links to papers on Consensus.

## Plans and Access
Your Consensus plan, not your AI subscription, sets how many papers each search returns, your monthly calls, whether results include DOIs and full-text excerpts, and whether Threads can use `deep` mode. No account is needed to try it.

## Tools
Consensus MCP exposes six tools. Your assistant picks the right one from your question.
| Tool | What it does |
| - | - |
| [`search`](https://docs.consensus.app/mcp-tools/search) | Find ranked, peer-reviewed papers for a query in one call. |
| [`get_full_text`](https://docs.consensus.app/mcp-tools/get-full-text) | Read the complete text of open-access papers from search results or Threads, as Markdown. |
| [`create_thread`](https://docs.consensus.app/mcp-tools/create-thread) | Start a Thread: hand a research question to the Consensus research agent. |
| [`get_thread`](https://docs.consensus.app/mcp-tools/get-thread) | Poll a Thread and read the agent's cited answer. |
| [`add_to_thread`](https://docs.consensus.app/mcp-tools/add-to-thread) | Ask a follow-up in an existing Thread. |
| [`find_threads`](https://docs.consensus.app/mcp-tools/find-threads) | List your Threads and find an earlier one. |
`search` works without an account. The thread tools need a signed-in Consensus account or an API key. `get_full_text` needs a paid plan.

## Troubleshooting
> [accordion] OAuth login is only supported for streamable HTTP servers (Codex)
>
> You added the server with `-- --transport http` instead of `--url`. Remove and re-add:
>
> ```bash theme={null}
> codex mcp remove consensus
> codex mcp add consensus --url https://mcp.consensus.app/mcp
> codex mcp login consensus
> ```
> [accordion] Authentication successful but server reconnection failed (Claude Code)
>
> Fully quit and restart Claude Code. Do not just use the reconnect option. Your credentials are saved and will work after restart.
> [accordion] Tools stop working after a few hours (401 errors)
>
> Your OAuth token has expired. Re-authenticate:
>
> * **Claude Code:** Type `/mcp`, select Consensus, choose Clear authentication, re-authenticate, then restart Claude Code
> * **Codex:** Run `codex mcp logout consensus` then `codex mcp login consensus`
> * **Cursor:** Disconnect and reconnect the server in Settings then Tools and MCP
> * **Claude Desktop:** Disconnect and reconnect the connector in Settings then Connectors
> * **ChatGPT:** Disconnect and reconnect the Consensus app from ChatGPT Apps
> * **Perplexity:** Disconnect and reconnect Consensus in Computer then Connectors
> [accordion] Server shows failed or no tools appear
>
> * Verify the URL includes `/mcp` at the end
> * Remove and re-add the server using the commands above
> * Restart your client completely
> [accordion] Consensus search has not been loaded yet (Claude Code)
>
> This is normal. Claude loads tool definitions on demand when many tools are present. Retry the query and it will work on the second attempt.
> [accordion] ChatGPT Deep Research is not using Consensus
>
> Confirm the Consensus app is connected in ChatGPT Apps, then ask Deep Research to use Consensus explicitly. For example:
>
> > Use Consensus to find peer-reviewed papers on this question and cite the strongest evidence.
>
> Deep Research decides when to call connected tools, so it may not call Consensus for questions that are not research-focused.
> [accordion] No results found
>
> Try broadening your search query or removing filters. Use specific academic terminology rather than casual language.
> [accordion] Monthly call limit reached
>
> Paid plans can continue making calls past the included monthly limit when the account has an active metered API subscription and additional usage is enabled; extra usage is billed at \$0.05 per call, with each call covering up to 100 papers. Free plans must wait for the next monthly reset or upgrade.
> [accordion] Rate limit exceeded (429 error)
>
> Rate limits are per user for authenticated MCP clients. A 429 that says you're sending requests too quickly is a per-minute rate limit; wait a few moments and add backoff between requests. A 429 that mentions monthly call credits is a usage limit, not a rate limit.
## Security
* **Endpoint:** Only connect to the official URL: `https://mcp.consensus.app/mcp`
* **API keys:** Store securely using environment variables. Never share keys in prompts or public conversations. Rotate if compromised.
* **Data handling:** Search queries are sent to the Consensus API over HTTPS/TLS. Results contain publicly available academic paper metadata. No personal data is stored from MCP requests.

## FAQ
> [accordion] Is there a PubMed MCP server with semantic search?
>
> Yes. Consensus covers all of PubMed plus the rest of science, ranked semantically rather than by keyword match alone. You can filter by study design, sample size, journal quartile and citation count. See [Where the papers come from](https://docs.consensus.app/get-started/where-papers-come-from.md).
> [accordion] What's the best MCP server for scientific literature in Claude?
>
> Consensus is in the [Claude connectors directory](https://claude.ai/directory/65247229-f0c7-49df-9044-fcbb8b3894c6) and works in Claude on the web, the Claude desktop app and [Claude Code](https://docs.consensus.app/mcp-clients/claude-code.md).
> [accordion] How do I add a scientific search connector to ChatGPT?
>
> Connect Consensus from the [ChatGPT app directory](https://chatgpt.com/plugins/plugin_asdk_app_6943e6f4a928819195962de16fb9ffe4). It also works with [ChatGPT Deep Research](#using-consensus-with-chatgpt-deep-research).
> [accordion] Can I use a research paper search MCP server in Cursor or VS Code?
>
> Yes. Install it in one click in [Cursor](https://docs.consensus.app/mcp-clients/cursor.md), or add the server URL to your MCP configuration in [VS Code (GitHub Copilot)](https://docs.consensus.app/mcp-clients/vs-code-github-copilot.md).
> [accordion] Which MCP server works for pharma and drug discovery?
>
> Consensus is SOC 2 Type II compliant, doesn't use customer data to train AI models, and offers a zero-data-retention option on enterprise agreements. It runs behind [AI gateways](https://docs.consensus.app/enterprise/gateways/overview.md) and in [Microsoft 365 Copilot](https://docs.consensus.app/enterprise/microsoft-365-copilot.md). Owkin uses it in its agentic AI scientist. See [Security and data handling](https://docs.consensus.app/enterprise/security.md).
> [accordion] Does it work for systematic reviews and meta-analyses?
>
> Yes. Filter by study design, including RCTs, systematic reviews and meta-analyses, and run deep literature reviews with Threads. See the [Threads quick start](https://docs.consensus.app/mcp-tools/quickstart.md).
> [accordion] Is this the same as Consensus (goconsensus.com)?
>
> No. This is Consensus, the AI academic search engine at [consensus.app](https://consensus.app). It's unrelated to the sales demo platform at goconsensus.com.
