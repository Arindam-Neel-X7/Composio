Integrations
Copy for LLM
Integrations let you combine Apify Actors with the rest of your stack - workflow automation platforms, data warehouses, AI agents, and the tools your team already uses. The sections below mirror the integrations sidebar; each links through to the full list.
Actors
Connect Apify Actors to other Actors and tasks to build multi-step workflows directly on the platform. Set up integration-ready Actors that take run output from an upstream Actor and push it into a downstream system.
Actor-to-Actor
Trigger other Actors or tasks from your Actor's runs.
Integration-ready Actors
Build Actors that act as integration targets.
See all Actor integrations →
Programming
Drive the Apify platform programmatically with the REST API, react to platform events through webhooks, and trigger Actors from your GitHub activity.
API
Control the Apify platform programmatically from your code.
Webhooks
Trigger external events when an Actor run succeeds or fails.
GitHub
Trigger Apify runs from GitHub events.
See all Programming integrations →
AI
Connect any MCP client to Apify through the Apify MCP server, use Actors in agents built on SDKs and frameworks such as OpenAI Agents, LangChain, and the Vercel AI SDK, and load the results into vector databases for retrieval.
Apify MCP server
Expose Apify Actors and storages to any MCP-compatible AI client.
OpenAI Agents SDK
Use Apify Actors as tools in agents built on the OpenAI Agents SDK.
LangChain
Wrap Apify Actors as LangChain tools for retrieval and agents.
Vercel AI SDK
Call Apify Actors from agents built on the Vercel AI SDK.
Google ADK
Add Apify Actors as tools in Google Agent Development Kit agents.
Pinecone
Embed and index scraped content in Pinecone for RAG.

Create a new integration
If you're building a service or platform and want your users to be able to connect it with Apify, create a new integration. The page walks through both routes - building an integration-ready Actor that other Apify users can plug into their workflows, or connecting your service to Apify externally via the API. If your team uses an AI coding agent, that page also covers the apify-integration-development skill, which guides the agent through the build.
If your tool isn't listed above, you can also browse Apify Store for community-built integration Actors like MongoDB Import or MySQL Insert.
