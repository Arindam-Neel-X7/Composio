Backlinks
Backlinks API provides real-time structured backlink data on virtually any domain, subdomain, or page on the web, including all relevant link, referring page and domain properties.
The following endpoints will help you obtain data on certain backlink properties and combine a well-rounded overview of websites’ link profiles:
Backlinks - target’s backlinks and related data;
Backlink history - historical data available back to 2019;
Backlink anchors - the details on backlinks’ anchors;
Backlink summary - a brief overview of the target’s backlink profile.
Relevant Domains
In addition to backlink data, this API is also capable of providing an advanced intel on relevant domains, thus allowing you to build a complete overview of the target domain as well as the websites referring to it.
By using the following endpoints, you will be able to search and extract all the domain-related data from our extensive link index:
Referring domains - detailed overview of referring websites;
Domain pages - backlink data for each page of the target domain;
Referring Networks - overview of referring IP networks.
Links Intersection
Link Intersection (or Link Gap) analysis is aimed at identifying domains pointing to several websites. The Link Gap feature allows users to uncover link opportunities by identifying domains that link out to competitors’ websites.
The following endpoints of Backlink Data API provide all the data you might need to implement the Link Gap feature:
Domain intersection - domains pointing to target websites;
Page intersection - pages pointing to target wesbites.
