MCP, CLI & Plugins
Copy page
Last updated Nov 1, 2026
Generate from Claude, coding agents, Figma and Adobe apps with your workspace credits. No API key needed.
Connect Higgsfield MCP
Connect from Claude
In Claude (web or desktop), open Settings → Connectors → Add custom connector.
Paste https://mcp.higgsfield.ai/mcp and click Connect.
Sign in to Higgsfield in the window that opens.
Start a new chat and ask "What is my Higgsfield credit balance?" to confirm it works.
Connect from ChatGPT
In ChatGPT, open Higgsfield’s connection page, choose Add Higgsfield in ChatGPT, and connect your Higgsfield account.
What you can do through MCP
Generate images and video; upscale, remove backgrounds, expand; use Kling Motion Control, Soul characters and Elements; create voiceover, voice clones and dubbing; send outputs to folders; run Ad Multiplier. Outputs appear in Assets. Voice clones: 5 per workspace by default (ask your account manager for more).
For a reference file in Claude, ask Higgsfield to open its upload window, upload there, and wait for confirmation before generating. A file attached only to the Claude chat is not automatically passed to Higgsfield.
CLI and Skills
Install Node.js and the Higgsfield CLI using the installation guide.
Run higgsfield auth login.
Run npx skills add higgsfield-ai/skills.
In Claude Code, Cursor or Codex, ask "Generate an image with Higgsfield".
Plugins and integrations
Figma and FigJam - generation, vector SVG, mockups, background removal; Canvas nodes in FigJam.
Photoshop - Generate AI Image, Realtime AI, Layer Decompose, Face Swap, Upscale.
Premiere Pro and After Effects - clips and B-roll to the timeline; Reframe, Remove Background, Edit Video.
DaVinci Resolve - generation, Draw to Video, Color Match, import to the Media Pool.
Minecraft mod.
