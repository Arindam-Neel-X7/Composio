Vonage CPaaS Power for Kiro
A Kiro Power that brings the Vonage Communications Platform directly into your AI-assisted development workflow. Go from zero to a working Vonage integration in minutes with guided, conversational workflows.

What Is This?
This Power connects Kiro to the Vonage CPaaS platform via two MCP servers:
Server
Description
vonage-api
Live API bindings for account management, phone numbers, applications, and activity reports
vonage-docs
Vonage developer documentation, SDK references, and code examples
Combined with steering files that encode best-practice workflows, Kiro can guide you through tasks like setting up a new Vonage application, purchasing a phone number, and pulling activity reports — all through natural conversation.
Prerequisites
Kiro installed and running
A Vonage API account (free to create)
Your Vonage API Key and Secret from the Vonage Dashboard
Installation
Clone this repository:
git clone https://github.com/Vonage/vonage-kiro-power.git
Set your Vonage credentials as environment variables before launching Kiro. The quickest way is a .env file in your project root:
VONAGE_API_KEY=your_api_key_here
VONAGE_API_SECRET=your_api_secret_here
Find both values at Vonage Dashboard → API Settings. See Configuration for the full list of variables.
Open the directory in Kiro — the Power is detected automatically from POWER.md. Kiro reads your environment variables and passes them to the MCP server on startup.
Credentials not set? When you trigger a workflow, the Power will detect missing credentials and walk you through the setup before proceeding.
Configuration
Set the following environment variables in your shell, a .env file, or directly in mcp.json.
Required for all workflows

Workflows
Get Started
Goes from credentials to a fully configured Vonage Application with a linked phone number.
Trigger phrases: "Set up Vonage", "Help me get started with Vonage", "Create a Vonage app", "Buy a number"
Steps:
Validates your API credentials against the live API
Creates a Vonage Application with your chosen capabilities (Messages, Voice, or both)
Searches for available phone numbers in your chosen country
Purchases and links the number to your application
Outputs all environment variables you need to continue building
Reports & Monitoring
Pulls activity records, visualizes data, and checks account balance.
Trigger phrases: "Show my reports", "Check message delivery", "Monitor usage", "Check my balance"
Steps:
Retrieves message and call records for a date range you specify (up to 30 days)
Filters by channel, destination number, status, or direction
Generates charts to visualize message volume, delivery rates, and channel distribution
Reports your current account balance with optional low-balance warnings

Documentation
The Vonage Docs MCP Server is always available for documentation lookups, code examples in any language, SDK references, and explanations of Vonage concepts.
Try: "Show me a Python example for sending an SMS" or "What is an NCCO?"
