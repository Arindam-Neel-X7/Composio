1
Open Claude Desktop and go to Customize → Connectors.
2
Click Add custom connector and paste the DataForSEO MCP HTTP URL:
https://mcp.dataforseo.com/v3/mcp
3
When prompted, approve the Authorization request to access the DataForSEO API.
4
Start a new chat. Claude will request your approval the first time it calls a DataForSEO tool.
1
Open the configuration file:
~/Library/Application Support/Claude/claude_desktop_config.json
On Windows: %APPDATA%\Claude\claude_desktop_config.json
2
Add the following configuration to the file:
JSON
Copy
{
"mcpServers": {
"dataforseo": {
"command": "npx",
"args": ["-y", "dataforseo-mcp-server"],
"env": {
"DATAFORSEO_USERNAME": "your_api_login",
"DATAFORSEO_PASSWORD": "your_api_password"
}
}
}
}
3
Replace your_api_login and your_api_password with credentials from the API Access dashboard.
4
Restart Claude Desktop. The DataForSEO tools will appear in your tool list.

Config file
1
Generate a Base64 token from your API login and password (or copy a pre-encoded one from the API Access
dashboard via the Send by Email button).
2
Add the remote DataForSEO MCP server in your terminal. Replace your_base64_encoded_token with the Base64 token from the previous step.
Bash
Copy
claude mcp add --header "Authorization: Basic your_base64_encoded_token>" --transport http dfs-mcp https://mcp.dataforseo.com/v3/mcp
3
Verify the connection:
Bash
Copy
claude mcp list
