## Your first request
Replace `YOUR_API_KEY` with a key from your [account settings](https://brightdata.com/cp/setting/users). You'll receive one JSON record. The same request pattern works for every scraper in the library.
```bash cURL theme={null}
curl "https://api.brightdata.com/datasets/v3/scrape?dataset_id=gd_l1viktl72bvl7bjuj0&format=json" \
-H "Authorization: Bearer YOUR_API_KEY" \
-H "Content-Type: application/json" \
-d '[{"url": "https://www.linkedin.com/in/elad-moshe-05a90413/"}]'
```
```python Python theme={null}
import requests
url = "https://api.brightdata.com/datasets/v3/scrape"
headers = {
"Authorization": "Bearer YOUR_API_KEY",
"Content-Type": "application/json",
}
params = {"dataset_id": "gd_l1viktl72bvl7bjuj0", "format": "json"}
payload = [{"url": "https://www.linkedin.com/in/elad-moshe-05a90413/"}]
response = requests.post(url, headers=headers, params=params, json=payload)
print(response.json())
```
```javascript Node.js theme={null}
const response = await fetch(
"https://api.brightdata.com/datasets/v3/scrape?dataset_id=gd_l1viktl72bvl7bjuj0&format=json",
{
method: "POST",
headers: {
"Authorization": "Bearer YOUR_API_KEY",
"Content-Type": "application/json",
},
body: JSON.stringify([
{ url: "https://www.linkedin.com/in/elad-moshe-05a90413/" },
]),
}
);
const data = await response.json();
console.log(data);
```

## How it works
Pick a request mode, then pick how you want the data delivered.
### Request modes
> [card] [Synchronous](https://docs.brightdata.com/concepts/sync-vs-async.md)
>
> One request, one response. Best for single URLs and real-time use cases.
> [card] [Asynchronous](https://docs.brightdata.com/products/scrapers/scrapers-library/async-requests.md)
>
> Trigger a job, retrieve later. Handles thousands of URLs per request.
> [card] [Discovery](https://docs.brightdata.com/products/scrapers/scrapers-library/faqs.md#what-is-the-difference-between-collect-and-discover-scrapers)
>
> Find records by keyword or category when you don't have specific URLs.
### Which delivery options to use
> [card] [API download](https://docs.brightdata.com/api-reference/scrapers/delivery-apis/download-snapshot.md)
>
> Pull results from the API once a job completes.
> [card] [Webhooks](https://docs.brightdata.com/products/scrapers/scrapers-library/data-delivery.md)
>
> Push results to your endpoint as soon as a snapshot is ready.
> [card] [Cloud storage](https://docs.brightdata.com/products/scrapers/scrapers-library/data-delivery.md)
>
> Deliver to S3, GCS, Azure, or Snowflake.
> [card] [Streaming](https://docs.brightdata.com/products/scrapers/scrapers-library/stream-and-file-delivery.md)
>
> Receive results in batches as they are scraped.

## Do I have to call the API directly?
No. The Bright Data SDKs, the CLI and coding-agent tools call the same Scraper API, so you can start from whichever fits your stack.
| Client | Install | First call |
| :- | :- | :- |
| **Python and Node.js SDK** | `pip install brightdata-sdk` or `npm install @brightdata/sdk` | Call `client.scrape.<platform>.<endpoint>(url="...")`; the method list is in the [Python SDK](https://docs.brightdata.com/api-reference/SDK.md) and [JavaScript SDK](https://docs.brightdata.com/api-reference/SDK-JS.md) |
| **CLI** | `npm install -g @brightdata/cli`, then `bdata login` | `bdata pipelines search "<site or data type>"` finds the scraper, `bdata pipelines info <dataset_id> <method>` shows its inputs, then run `bdata pipelines run <dataset_id> <method> "<url>" --pretty`; see the [CLI commands](https://docs.brightdata.com/products/cli/commands.md) |
| **Coding agents** | `npx skills add brightdata/skills` installs the skills; the [Bright Data MCP](https://docs.brightdata.com/products/mcp-server/overview.md) server exposes the scrapers as tools | See the [coding agent quickstart](https://docs.brightdata.com/quickstart-coding-agent.md) |
