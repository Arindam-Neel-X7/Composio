1. What We Found (The 2-Minute Takeaway)

44/100 apps (44.00%) can be built immediately with self-serve credentials (34 already ship official MCP servers). Another 50/100 (50.00%) have functional APIs/MCPs but require tenant admin consent, vendor app review, or paid subscriptions before production operation.

2. The Testing-to-Production Gating Trap

While 62/100 (62.00%) allow self-serve testing, only 49/100 (49.00%) allow self-serve production deployment. Mandatory paid plans surge from 1/100 (1.00%) in testing to 36/100 (36.00%) in production (+35 net shift).

3. MCP & Auth Reality

85/100 apps (85.00%) have documented MCP server implementations (70 official, 19 community, 4 overlap). OAuth 2.0 (79/100) dominates authentication, while API Keys (39/100) and Bearer Tokens (35/100) power headless self-serve access.

4. Honest Human Verification

Independent human reviewer ARINDAM KARMAKAR audited all 327 claims across the frozen 20-app stratified sample. Baseline accuracy was 84.71% (277 correct, 50 unsupported). After 50 immutable corrections, recheck accuracy reached 100.00% on fixed N=327.

The remaining 80 apps retain their sealed, AI-audited first-pass records. All MCP operational runtime checks remain strictly not_researched (no live credentials or tool invocations were executed).

7. Misses, Gaps & Project Limitations

1. Sample Reuse Disclosure

The 100.00% post-correction accuracy (327/327 claims) reflects verified remediation on the same 20-app stratified sample (composio-20app-sample-v1) audited in Task 17. It proves the 50 baseline defects were genuinely fixed without inventory drift, but it is not an unbiased held-out estimate for the 80 unsampled apps.

2. Operational MCP Checks Unresearched

By design, no paid accounts, OAuth token exchanges, or live MCP tool invocations were performed. Every MCP entry's operational check status remains strictly not_researched. Documentary existence of an official or community MCP repo does not guarantee runtime stability or tool-schema completeness.

3. Single-Rater Human Baseline

All 327 baseline and recheck adjudications were completed by a single identified human reviewer (ARINDAM KARMAKAR). While this eliminates AI self-grading, future production benchmarks should measure inter-annotator agreement across multiple independent reviewers.

4. Capture Walls & Documentation Drift

Two applications (App 84 Paygent Connect, App 90 PitchBook) remain blocked due to vendor naming ambiguity and HTTP 403 bot walls. Furthermore, unversioned SaaS developer docs evolve over time; local SHA-256 snapshots freeze the exact text observed during November 2026.
